Architecture Overview

The platform is composed of several independently deployable services. Each service owns its data store and communicates via internal HTTP APIs. There is no shared database.

Key services: auth-service, api-gateway, worker, and static-server (this server). All services run on Node.js 20+ with zero external runtime dependencies.

Deployment is handled via a simple node server.js invocation on each host. Configuration is injected through config.json at the project root.

Runbook

If a site fails to start (port already in use), the server logs the error and continues bringing up the remaining sites. To diagnose:

  • Check which process owns the port: netstat -ano | findstr :PORT
  • Restart the offending process or choose a different port in config.json
  • Re-run node server.js

To gracefully shut down all sites, press Ctrl+C in the terminal where the server is running.
